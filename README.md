# LexJab Sim

Симулятор алгоритму повторення юнітів для мобільного додатку LexJab.

Сайт перевіряє правила черги повторень на тисячах прогонів. Він працює в браузері на будь-якому пристрої, зокрема на планшеті.

## Стан

Етап 1 — режим дедлайну. Готові документація і модуль `packages/core` (версія алгоритму 0.1.0) з тестами. Модель учня і сайт — далі.

## Документи

- [Декларація](doc/declaration.md) — мета, рішення, режими, результати, етапи.
- [Вимоги першої версії](doc/requirements.md) — режим дедлайну: правила алгоритму, функції сайту, вимоги до модуля.
- [ТЗ-01. Модуль `core`: черга під дедлайн](doc/tz-01-core-deadline.md) — норма для модуля: стан, операції, контрольні приклади.

## Структура (план)

- `packages/core` — модуль алгоритму, спільний для симулятора і додатку.
- `packages/sim` — модель учня, прогони, статистика.
- `apps/web` — сайт (GitHub Pages).

Стек: Vite + React + TypeScript.
