# LexJab Sim

Симулятор алгоритму повторення юнітів для мобільного додатку LexJab.

Сайт перевіряє правила черги повторень на тисячах прогонів. Він працює в браузері на будь-якому пристрої, зокрема на планшеті.

**Сайт:** https://airteg.github.io/lexjab-sim/

## Стан

Етап 1 — режим дедлайну. Готові документація, модуль `packages/core` (версія алгоритму 0.1.0), модуль `packages/sim` (версія симулятора 0.1.0) і сайт `apps/web`.

Сторінки сайту:
- **Константи** — усі параметри з реєстру; змінені відносно норми ТЗ позначені; профілі учня одним натиском; значення зберігаються в браузері.
- **Прогін** — один прогін за зерном: показники і повна карта (юніти × уроки, оцінки кольором, заповнювачі, кінці раундів); журнал у CSV, прогін у JSON.
- **Серія** — багато прогонів у фоновому потоці: мінімум і оптимум з гарантією, інші показники; будь-який прогін серії можна розгорнути; серія в JSON.

## Структура

- `packages/core` — модуль алгоритму, спільний для симулятора і додатку.
- `packages/sim` — модель учня, прогони, статистика.
- `apps/web` — сайт (GitHub Pages).

Стек: Vite + React + TypeScript 6, ESLint.
