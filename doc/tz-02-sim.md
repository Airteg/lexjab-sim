# ТЗ-02. Модуль `sim`: модель учня, прогони, показники

Версія симулятора: **0.1.0** · 18.11.2026 · Віталій

Це ТЗ — норма для модуля `packages/sim`. Симулятор = модуль `core` (ТЗ-01) + вигаданий учень.

Джерела: документ «Експеримент 2» (17.11.2026) і його Python-код, `doc/requirements.md`, рішення Віталія від 18.11.2026 (позначені **[18.11]**).

## 1. Межі

`sim`:
- генерує оцінки за моделлю учня;
- проганяє колоду через `core` і веде журнал;
- рахує показники одного прогону і серії прогонів;
- містить реєстр констант для сторінки «Константи».

`sim` не змінює правил черги: склад уроку й зміну стану визначає лише `core`. `sim` не знає про інтерфейс.

## 2. Випадковість

- Усі випадкові числа беруться з генератора із зерном (seed). Те саме зерно дає той самий прогін.
- Генератор — mulberry32 (32-бітний, рівномірні числа в [0; 1)). Це деталь реалізації, а не правило алгоритму. Але зміна генератора змінює результати, тому вона змінює версію симулятора.
- У серії прогін № i (від 0) отримує зерно `BASE_SEED + i`.

## 3. Модель учня «Експеримент 2» (метод `exp2`)

Параметри: C1, D1, E1.

Для кожного юніта уроку, по черзі в порядку складу уроку, береться одне випадкове число x ∈ [0; 1):

1. a = C1, якщо юніт ще жодного разу не мав успіху («3» або «5»); інакше a = 0.
2. b = min(D1 × E1^k, 1 − a), де k — скільки «5» юніт отримав за весь прогін.
3. Оцінка: «1», якщо x < a; «3», якщо x < a + b; інакше «5».

Лічильники успіхів і «5» ведуться за весь прогін, а не в межах раунду. Звідси випливає: після першого успіху «1» не випадає, тож заповнювач отримує лише «3» або «5».

Профілі:

| Учень | C1 | D1 | E1 |
|---|---|---|---|
| середній | 0,3 | 0,5 | 0,7 |
| слабкий | 0,6 | 0,7 | 0,85 |
| дуже слабкий | 0,7 | 0,8 | 0,9 |

Ці числа вигадані, а не виміряні на реальних учнях. Нові методи генерації оцінок додаються поруч із `exp2`; старі не переписуються.

## 4. Прогін

**Вхід:**
- розмір колоди (юніти U0, U1, … у такому порядку);
- налаштування колоди (ТЗ-01 §4.2);
- константи алгоритму (ТЗ-01 §3);
- метод і параметри моделі учня;
- зерно;
- `ROUNDS_PER_RUN`, `MAX_TESTS_PER_UNIT`.

**Хід:** урок за уроком: `nextLesson`, далі кожен юніт уроку отримує оцінку від моделі учня і проходить через `applyGrade`.

**Завершення раунду k:** після уроку, у якому вийшли з раунду всі юніти. Номер цього уроку — кінець раунду k.

**Зупинка:** **[18.11]**
- завершено `ROUNDS_PER_RUN` раундів — прогін завершений;
- або кількість тестувань досягла `MAX_TESTS_PER_UNIT` × розмір колоди — прогін **не завершений**.

**Журнал:** для кожного уроку — номер, раунд, склад, і для кожного юніта: оцінка, чи був він заповнювачем, EF до і після оцінки.

## 5. Показники прогону

| Показник | Визначення |
|---|---|
| Кінець раунду k | Номер уроку, після якого завершився раунд k; немає, якщо прогін не дійшов |
| Тестувань на юніт до кінця раунду k | Усі тестування до цього уроку включно ÷ розмір колоди |
| Днів до кінця раунду k | Номер уроку ÷ уроків на день |
| Урок першого тесту останнього юніта | Найбільший серед юнітів номер уроку, де юніт тестувався вперше |
| Чи лишився неперевірений юніт | Чи є юніт, що жодного разу не тестувався за прогін |
| Повернення після «1» | Для кожної «1»: через скільки уроків юніт знову потрапив в урок. Середнє й максимум за прогін |
| Найдовша серія | Найбільша кількість уроків поспіль, у яких був один і той самий юніт |
| Вільні місця | Скільки місць в уроках лишилося порожніми |
| Місця заповнювачів | Скільки місць в уроках зайняли заповнювачі |

Останні два показники додано, щоб на великих колодах побачити, чи з'являються «дірки», коли юніти отримують дві «5» поспіль.

## 6. Серія прогонів

`RUNS` прогонів з однаковими входами і зернами `BASE_SEED`, `BASE_SEED + 1`, …

| Показник серії | Визначення |
|---|---|
| Кінець раунду k з гарантією P% | Процентиль P (за найближчим рангом) кінців раунду k. Незавершений прогін вважається нескінченно довгим; якщо незавершених більше ніж (100 − P)%, показник — «не завершено» |
| Тестувань на юніт і днів з гарантією P% | Те саме для цих показників |
| Мінімум | Раунд 1 з гарантією P% |
| Оптимум | Раунд 2 з гарантією P% |
| Частка незавершених прогонів | — |
| Частка прогонів із неперевіреним юнітом | — |
| Урок першого тесту останнього юніта | Середнє й максимум за прогонами |
| Повернення після «1» | Середнє й максимум за всіма випадками «1» в усіх прогонах разом |
| Найдовша серія | Середнє й максимум за прогонами |
| Вільні місця, місця заповнювачів | Середнє на прогін |

Процентиль за найближчим рангом: значення на місці ⌈P / 100 × n⌉ у відсортованому за зростанням ряді з n значень.

Кожна константа має: ключ, назву українською, пояснення, значення за замовчуванням, межі, посилання на ТЗ. Сторінка «Константи» будується з реєстру.

| Група | Ключ | Назва | За замовчуванням | Межі | ТЗ |
|---|---|---|---|---|---|
| Колода й урок | `DECK_SIZE` | Юнітів у колоді | 20 | ціле ≥ 1 | 02 §4 |
| | `UNITS_PER_LESSON` | Юнітів в уроці | 5 | ціле ≥ 1 | 01 §4.2 |
| | `LESSONS_PER_DAY` | Уроків на день | 5 | ціле ≥ 1 | 01 §4.2 |
| Алгоритм | `EF_DELTA_1` / `_3` / `_5` | Зміна EF за «1» / «3» / «5» (соті) | −54 / −14 / +10 | ціле | 01 §3 |
| | `EF_MIN` | Мінімальний EF (соті) | 130 | ціле ≥ 1 | 01 §3 |
| | `EF_START` | Стартовий EF (соті) | 130 | ціле ≥ `EF_MIN` | 01 §3 |
| | `EXIT_STREAK` | «5» поспіль для виходу з раунду | 2 | ціле ≥ 1 | 01 §3 |
| | `FILLER_RETURN_GRADES` | Оцінки, що повертають заповнювача | {1} | підмножина {1, 3, 5} | 01 §3 |
| Модель учня | `LEARNER_METHOD` | Метод генерації оцінок | `exp2` | зі списку методів | 02 §3 |
| | `C1` | Імовірність «1» до першого успіху | 0,3 | 0…1 | 02 §3 |
| | `D1` | Імовірність «3» на старті | 0,5 | 0…1 | 02 §3 |
| | `E1` | Множник імовірності «3» за кожну «5» | 0,7 | 0…1 | 02 §3 |
| Прогін і серія | `ROUNDS_PER_RUN` | Раундів у прогоні | 2 | ціле ≥ 1 | 02 §4 **[18.11]** |
| | `MAX_TESTS_PER_UNIT` | Аварійна межа: тестувань на юніт | 100 | ціле ≥ 1 | 02 §4 **[18.11]** |

| | `PERCENTILE` | Гарантія, % | 90 | 1…100 | 02 §6 |

Значення за замовчуванням: 20 юнітів, 5 в уроці, 5 уроків на день, середній учень, 1000 прогонів, гарантія 90% — як в основному прогоні експерименту 2. Межі — лише природні (ймовірність від 0 до 1, кількість ≥ 1).

## 8. Перевірка

- Модель учня: на великій кількості випадкових чисел частоти оцінок збігаються з формулами §3 у межах статистичної похибки; «1» після першого успіху не випадає.
- Відтворюваність: те саме зерно дає той самий журнал.
- Зупинка за раундами й за аварійною межею.
- Показники §5 перевіряються на прогонах, де оцінки задано вручну, а не моделлю учня.
