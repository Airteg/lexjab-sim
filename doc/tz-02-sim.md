# ТЗ-02. Модуль `sim`: модель учня, прогони, показники

Версія симулятора: **0.2.0** · 23.11.2026 · Віталій

Це ТЗ — норма для модуля `packages/sim`. Симулятор = модуль `core` (ТЗ-01) + вигаданий учень.

Джерела: документ «Експеримент 2» (17.11.2026) і його Python-код, `doc/requirements.md`, рішення Віталія від 18.11.2026 (позначені **[18.11]**) і 23.11.2026 (позначені **[23.11]**).

Значення, позначені *(вигадано)*, придумав Claude як стартові для експериментів **[23.11]**. Вони не виміряні й не взяті з експерименту 2.

## 1. Межі

`sim`:
- генерує оцінки за моделлю учня;
- проганяє колоду через `core` і веде журнал;
- рахує показники одного прогону і серії прогонів;
- містить реєстр констант для сторінки «Константи».

`sim` не змінює правил черги: склад уроку й зміну стану визначає лише `core`. `sim` не знає про інтерфейс.

## 2. Випадковість

- Усі випадкові числа беруться з генератора із зерном (seed). Те саме зерно дає той самий прогін.
- Генератор — mulberry32 (32-бітний, рівномірні числа в [0; 1)). Це деталь реалізації, а не правило алгоритму. Але зміна генератора змінює результати, тому вона змінює версію симулятора.
- У серії прогін № i (від 0) отримує зерно `BASE_SEED + i`.
- Модель учня бере числа з того самого генератора, що й прогін. Модель «Змішана колода» спершу бере по одному числу на юніт (§3.5), а потім — по одному на оцінку.

## 3. Моделі учня **[23.11]**

Модель учня — правило, за яким симулятор ставить оцінки. Живого учня немає. Нові моделі додаються поруч зі старими; старі не переписуються.

Що модель знає про юніт (лічильники за весь прогін, а не за раунд):
- **успіхів** — скільки разів юніт отримав «3» або «5»;
- **«5»** — скільки разів юніт отримав «5» (k).

Кожна оцінка, крім моделі «Ідеальний», бере одне випадкове число x ∈ [0; 1) і знаходить шанси a («1») та b («3»). Оцінка: «1», якщо x < a; «3», якщо x < a + b; інакше «5». Шанс «5» = 1 − a − b.

На сторінці «Константи» під списком моделей показано її опис і таблицю шансів «1» / «3» / «5» для поточних параметрів.

### 3.1. Ідеальний (`ideal`)

Завжди «5». Параметрів немає, випадкових чисел не бере. Показує нижню межу: швидше пройти колоду неможливо.

### 3.2. Кубик (`dice`)

Кожен тест — однакові шанси, незалежно від історії юніта: a = P1, b = P3, «5» — решта.

| Параметр | За замовчуванням |
|---|---|
| P1 — шанс «1» | 0,2 *(вигадано)* |
| P3 — шанс «3» | 0,4 *(вигадано)* |

Обмеження: P1 + P3 ≤ 1. «1» може випасти будь-коли. Еталон для порівняння з іншими моделями.

### 3.3. Вчиться (`exp2`, модель «Експеримент 2»)

Параметри: C1, D1, E1.

1. a = C1, якщо юніт ще жодного разу не мав успіху; інакше a = 0.
2. b = min(D1 × E1^k, 1 − a).

Звідси: після першого успіху «1» не випадає, тож заповнювач отримує лише «3» або «5».

Профілі:

| Учень | C1 | D1 | E1 |
|---|---|---|---|
| сильний **[23.11]** | 0,1 *(вигадано)* | 0,3 *(вигадано)* | 0,5 *(вигадано)* |
| середній | 0,3 | 0,5 | 0,7 |
| слабкий | 0,6 | 0,7 | 0,85 |
| дуже слабкий | 0,7 | 0,8 | 0,9 |

Числа середнього, слабкого й дуже слабкого учня вигадані в експерименті 2, а не виміряні на реальних учнях.

Шанси «1» / «3» / «5», %:

| Учень | Доки не згаданий | Після успіху, k = 0 | k = 1 | k = 2 | k = 3 |
|---|---|---|---|---|---|
| сильний | 10 / 30 / 60 | 0 / 30 / 70 | 0 / 15 / 85 | 0 / 8 / 92 | 0 / 4 / 96 |
| середній | 30 / 50 / 20 | 0 / 50 / 50 | 0 / 35 / 65 | 0 / 24 / 76 | 0 / 17 / 83 |
| слабкий | 60 / 40 / 0 | 0 / 70 / 30 | 0 / 60 / 40 | 0 / 51 / 49 | 0 / 43 / 57 |
| дуже слабкий | 70 / 30 / 0 | 0 / 80 / 20 | 0 / 72 / 28 | 0 / 65 / 35 | 0 / 58 / 42 |

Слабкий і дуже слабкий учень не отримують «5», доки юніт не згаданий: C1 + D1 ≥ 1.

### 3.4. Забуває (`forget`)

Як «Вчиться», але після першого успіху «1» випадає з шансом F.

1. a = C1, якщо юніт ще жодного разу не мав успіху; інакше a = F.
2. b = min(D1 × E1^k, 1 − a).

Шанс «1» береться з шансу «5»: «3» лишається таким, як у «Вчиться», поки D1 × E1^k ≤ 1 − F. Після «1» юніт лишається юнітом, що вже мав успіх: a не повертається до C1.

| Параметр | За замовчуванням |
|---|---|
| C1, D1, E1 | спільні з «Вчиться» (середній учень) |
| F — шанс забути | 0,05 *(вигадано)* |

### 3.5. Змішана колода (`mixed`)

Перед першим уроком кожен юніт, по черзі в порядку колоди, отримує складність за одним випадковим числом y:
- легкий, якщо y < Л;
- середній, якщо y < Л + С;
- інакше важкий.

Далі юніт оцінюється за правилом «Вчиться» з профілем: легкий — сильний учень, середній — середній, важкий — слабкий (§3.3).

| Параметр | За замовчуванням |
|---|---|
| Л — частка легких | 0,3 *(вигадано)* |
| С — частка середніх | 0,5 *(вигадано)* |

Обмеження: Л + С ≤ 1. Частка важких — решта (за замовчуванням 0,2).

## 4. Прогін

**Вхід:**
- розмір колоди (юніти U0, U1, … у такому порядку);
- налаштування колоди (ТЗ-01 §4.2);
- константи алгоритму (ТЗ-01 §3);
- модель учня та її параметри;
- зерно;
- `ROUNDS_PER_RUN`, `MAX_TESTS_PER_UNIT`.

**Хід:** урок за уроком: `nextLesson`, далі кожен юніт уроку отримує оцінку від моделі учня і проходить через `applyGrade`.

**Карта прогону** **[23.11]:** сторінка «Прогін» малює карту (юніти × уроки), лише якщо юнітів у колоді не більше `MAP_MAX_UNITS`. Інакше карта не малюється; повні дані прогону — у журналі (кнопка «Журнал CSV»). На розрахунок прогону межа не впливає.

**Завершення раунду k:** після уроку, у якому вийшли з раунду всі юніти. Номер цього уроку — кінець раунду k.

**Зупинка:** **[18.11]**
- завершено `ROUNDS_PER_RUN` раундів — прогін завершений;
- або кількість тестувань досягла `MAX_TESTS_PER_UNIT` × розмір колоди — прогін **не завершений**.

**Журнал:** для кожного уроку — номер, раунд, склад, і для кожного юніта: оцінка, чи був він заповнювачем, EF до і після оцінки.

## 5. Показники прогону

| Показник | Визначення |
|---|---|
| Кінець раунду k | Номер уроку, після якого завершився раунд k; немає, якщо прогін не дійшов |
| Тестувань на юніт до кінця раунду k | Усі тестування до цього уроку включно ÷ розмір колоди |
| Днів до кінця раунду k | Номер уроку ÷ уроків на день |
| Урок першого тесту останнього юніта | Найбільший серед юнітів номер уроку, де юніт тестувався вперше |
| Чи лишився неперевірений юніт | Чи є юніт, що жодного разу не тестувався за прогін |
| Повернення після «1» | Для кожної «1»: через скільки уроків юніт знову потрапив в урок. Середнє й максимум за прогін |
| Найдовша серія | Найбільша кількість уроків поспіль, у яких був один і той самий юніт |
| Вільні місця | Скільки місць в уроках лишилося порожніми |
| Місця заповнювачів | Скільки місць в уроках зайняли заповнювачі |

Останні два показники додано, щоб на великих колодах побачити, чи з'являються «дірки», коли юніти отримують дві «5» поспіль.

## 6. Серія прогонів

`RUNS` прогонів з однаковими входами і зернами `BASE_SEED`, `BASE_SEED + 1`, …

| Показник серії | Визначення |
|---|---|
| Кінець раунду k з гарантією P% | Процентиль P (за найближчим рангом) кінців раунду k. Незавершений прогін вважається нескінченно довгим; якщо незавершених більше ніж (100 − P)%, показник — «не завершено» |
| Тестувань на юніт і днів з гарантією P% | Те саме для цих показників |
| Мінімум | Раунд 1 з гарантією P% |
| Оптимум | Раунд 2 з гарантією P% |
| Частка незавершених прогонів | — |
| Частка прогонів із неперевіреним юнітом | — |
| Урок першого тесту останнього юніта | Середнє й максимум за прогонами |
| Повернення після «1» | Середнє й максимум за всіма випадками «1» в усіх прогонах разом |
| Найдовша серія | Середнє й максимум за прогонами |
| Вільні місця, місця заповнювачів | Середнє на прогін |

Процентиль за найближчим рангом: значення на місці ⌈P / 100 × n⌉ у відсортованому за зростанням ряді з n значень.

### 6.1. Серія «Усі учні» **[23.11]**

Одна кнопка на сторінці «Константи». Ті самі входи серії (колода, алгоритм, прогони, зерна, гарантія) проганяються по черзі для 8 учнів:

1. Ідеальний;
2. Кубик — з поточними P1, P3;
3–6. Вчиться — сильний, середній, слабкий, дуже слабкий (числа профілів з §3.3, а не поточні C1, D1, E1);
7. Забуває — з поточними C1, D1, E1, F;
8. Змішана колода — з поточними Л, С.

Кожен учень отримує ті самі зерна. Результат — таблиця: рядок на учня з його параметрами; для кожного раунду — уроків, днів і тестувань на юніт з гарантією P%; частка незавершених прогонів.

## 8. Перевірка

- Моделі учня: на великій кількості випадкових чисел частоти оцінок збігаються з формулами §3 у межах статистичної похибки; у «Вчиться» «1» після першого успіху не випадає; частки складності в «Змішаній колоді» збігаються з Л і С.
- Генератор **[23.11]** (зерно 1, якщо не сказано інше):
  - рівномірність: 1 000 000 чисел у 100 рівних кошиках, χ² < 148 (межа для 99 ступенів свободи на рівні 0,001);
  - зв'язок сусідніх чисел одного потоку: |кореляція| < 0,005 на 1 000 000 пар;
  - сусідні зерна (s і s + 1, s = 1…100 000): для 1-го, 2-го й 11-го числа |кореляція| < 0,016, χ² у 100 кошиках < 148.
  Межі — приблизно 5 стандартних похибок; генератор детермінований, тож перевірка не «мигає».
- Серія «Усі учні»: 8 рядків у порядку §6.1; рядок учня збігається зі звичайною серією для цього учня.
- Відтворюваність: те саме зерно дає той самий журнал.
- Зупинка за раундами й за аварійною межею.
- Показники §5 перевіряються на прогонах, де оцінки задано вручну, а не моделлю учня.
